MojePierwszeRepo

Repozytorium zostało utworzone w ramach ćwiczenia z pracy z systemem kontroli wersji Git oraz platformą GitHub.

Opis projektu

Projekt zawiera prosty program w języku C# przedstawiający grę Saper. W ramach zadania wykonano analizę kodu, znaleziono błędy, utworzono zgłoszenia Issues, wykonano poprawki na osobnych gałęziach oraz scalono zmiany za pomocą Pull Requestów.

Wykonane elementy

- utworzenie repozytorium,
- dodanie plików,
- utworzenie gałęzi,
- wykonanie Pull Requestów,
- recenzja i zatwierdzenie zmian,
- utworzenie Issues,
- naprawa błędów w kodzie,
- commitowanie zmian,
- aktualizacja lokalnego repozytorium,
- dodanie dokumentacji README.

Uruchomienie

Kod programu znajduje się w pliku `saper.txt`. Aby uruchomić program jako aplikację konsolową C#, można skopiować kod do pliku `Program.cs` w projekcie konsolowym C# i uruchomić go w środowisku Visual Studio lub za pomocą .NET CLI.
